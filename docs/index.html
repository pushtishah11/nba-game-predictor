🏀 NBA Game Predictor

Daily win probabilities from an Elo + recent-form model. Picks are logged before tip-off.

How it works

Every morning a scheduled job downloads the latest scores from Basketball-Reference, rebuilds each team's features, and predicts the next week of games. The features are:

  • Elo rating: one number per team that goes up with wins (more for big wins over good teams) and down with losses
  • Season form: win % and average point margin
  • Recent form: win % and margin over the last 10 games
  • Rest: days off, and whether a team is on the second night of a back-to-back
  • Home court (except at neutral sites)

A logistic regression turns those into a probability. It was tested walk-forward: to score each season, it trained only on earlier seasons. Across games it picked of winners correctly, vs for always picking the home team.

The live track record only counts picks the site published before the game started.
